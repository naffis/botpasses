# Security

If you find a security problem in Botpasses, the hosted service, or this repository, email **security@botpasses.com** privately. Do not open a public GitHub issue.

The same address is in [`/.well-known/security.txt`](https://botpasses.com/.well-known/security.txt). The full process, what to include, and what is in scope are on [Security disclosure](https://botpasses.com/docs/security/disclosure).

We reply from `security@botpasses.com` to confirm receipt. We will tell you when a fix ships and credit you in the changelog if you want that. Please give us time to fix the issue before publishing details.
